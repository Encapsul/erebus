# site-packages-only

Python app with a vendored `site-packages/` tree and **no** `requirements.txt`.

```bash
erebus build ./examples/site-packages-only -o /tmp/sp.erebus --force
/tmp/sp.erebus
# → hello from vendored site-packages
```

The stub injects `PYTHONPATH` when `app/site-packages` exists in the rootfs.
